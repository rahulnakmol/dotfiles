# Claude rules

`CLAUDE.md` is the always-loaded spine. Everything here is path-scoped —
loads only when Claude touches a matching file — except `010-secrets.md`,
which is always on.

| File | Loads on |
|------|----------|
| `010-secrets.md` | always |
| `python.md` | `*.py`, `requirements*.txt`, `pyproject.toml` |
| `go.md` | `*.go`, `go.mod`, `go.sum` |
| `dotnet.md` | `*.cs`, `*.csproj`, `Directory.Build.props` |
| `typescript.md` | `*.ts`, `*.tsx`, `tsconfig.json` |
| `terraform.md` | `*.tf`, `*.tfvars`, `.terraform.lock.hcl` |
| `docker.md` | `Dockerfile`, `*.dockerfile`, `docker-compose*.yml`, `.dockerignore` |
| `cloud-azure.md` | `azure/`, `infra/azure/`, `*.azure.tf`, `*.bicep`, `azure-pipelines.yml` |
| `cloud-gcp.md` | `gcp/`, `infra/gcp/`, `*.gcp.tf`, `cloudbuild.yaml`/`.yml` |
| `agentic-ai.md` | `agents/`, `agent/`, `*agent*.py`, `*rag*.py`, `tools/` |
| `power-platform-dynamics.md` | `solution.xml`, `*.sppkg`, `customizations.xml`, `*.cdsproj` |

Regenerated by `node scripts/apply-agent-policy.mjs`: `010-secrets.md` only
(the warning-section body). Everything else here is hand-authored.
