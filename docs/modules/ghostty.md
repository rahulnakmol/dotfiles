# ghostty

Ghostty terminal emulator configuration.

## Key Files

| File | Purpose |
|------|---------|
| `.config/ghostty/config` | Terminal settings |

## Settings

| Setting | Value |
|---------|-------|
| Theme | Catppuccin Macchiato |
| Font | Mononoki Nerd Font |
| Font size | 16 |
| Window height | 50 |
| Window width | 200 |
| Padding (x/y) | 20 |
| Background opacity | 0.95 |
| Background blur | true |
| Shell integration | zsh |
| SSH terminfo | enabled via `shell-integration-features` |

## Dependencies

Ghostty, Mononoki Nerd Font.
